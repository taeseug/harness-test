# 🔍 Wiki 콘텐츠 검증 스킬 (LLM Review)

## 📋 개요

Wiki 파일이 실제 회의 내용과 **정확하게 일치**하는지 LLM이 검증합니다.

```
원본 회의록 + 생성된 Wiki 파일
    ↓
Claude LLM 비교 분석
    ↓
검증 결과 (일치도, 오류, 누락, 액션 상태)
    ↓
최종 품질 평점 (A+~F)
```

---

## 🎯 검증 항목

### 1️⃣ 일치도 (Content Alignment)
- **회의 내용과 wiki가 일치하는가?**
- 요약이 정확한가?
- 주요 논점이 빠지지 않았는가?

### 2️⃣ 허구 생성 여부 (Hallucination Detection)
- wiki에만 있는 내용이 있는가?
- 원본 회의록에 없는 액션이 추가되었는가?
- 잘못된 정보가 있는가?

### 3️⃣ 누락된 내용 (Completeness)
- 중요한 액션이 빠졌는가?
- 결정사항이 모두 기록되었는가?
- 위험 요소나 우려사항이 누락되었는가?

### 4️⃣ 액션 상태 추적 (Action Status)
- 액션의 상태가 정확한가? (열림/홀드/완료)
- 담당자가 명확한가?
- 마감일이 합리적인가?

## 🚀 사용 방법

### 방법 1️⃣: 파일명으로 요청

```
"2026-06-11 회의 wiki를 검증해줄래?
원본은 llm-ssot/Meetings/2026-06-11*.enhanced.md이고
생성된 wiki는 obsidian-vault/Meetings/2026-06-11*.md 파일이야"
```

### 방법 2️⃣: 전체 wiki 검증

```
"obsidian-vault/Meetings 폴더의 모든 wiki를 검증해줄래?
각 wiki마다 원본 회의록과 비교해서"
```

### 방법 3️⃣: 특정 항목만 검증

```
"2026-06-11 회의:
- 액션 아이템들의 담당자가 정확한가?
- 누락된 결정사항이 있나?
- 허구로 생성된 내용이 있나?
를 중점적으로 검증해줄래?"
```

### 방법 4️⃣: 액션 상태 추적만 검증

```
"현재까지의 회의들에서:
- 어떤 액션들이 여전히 '열림' 상태인가?
- 홀드된 액션은?
- 조용히 사라진 액션은?
추적해줄래?"
```

## 📝 검증 프로세스

### Step 1: 파일 읽기
- 원본 회의록 (`llm-ssot/Meetings/`) 읽기
- 생성된 wiki 파일 (`obsidian-vault/Meetings/`) 읽기

### Step 2: 내용 비교
- 주제별 일치도 확인
- 누락된 내용 식별

### Step 3: 오류 탐지
- 허구 생성 여부 검사
- 잘못된 정보 확인

### Step 4: 액션 추적
- 각 액션의 담당자, 마감일, 상태 검증
- 액션 상태 변화 추적

### Step 5: 최종 평가
- 종합 점수 산출
- 개선 사항 제시

## 🎓 평가 기준

### 일치도 (Alignment)
- **90점 이상**: 거의 모든 내용 일치
- **80-89점**: 대부분 일치, 사소한 누락
- **70-79점**: 중요 내용 포함, 일부 누락
- **60-69점**: 일부 누락, 명확하지 않음
- **60점 미만**: 주요 내용 누락

### 허구 (Hallucination)
- **없음**: 0개 - 우수
- **경미**: 1-2개, 영향 적음
- **중간**: 3-5개, 일부 영향
- **심각**: 5개 이상, 신뢰도 낮음

### 완성도 (Completeness)
- **95점 이상**: 모든 내용 포함
- **85-94점**: 대부분 포함, 주석 추가 필요
- **75-84점**: 일부 누락, 개선 필요
- **65-74점**: 주요 누락, 수정 필요
- **65점 미만**: 다시 작성 권장

### 액션 추적 (Action Tracking)
- **완벽**: 모든 액션 상태 정확
- **양호**: 90% 정확
- **보통**: 75% 정확
- **미흡**: 60% 정확
- **부족**: 60% 미만

## 📚 결과 해석

### 평점별 해석

| 등급 | 점수 | 의미 | 조치 |
|------|------|------|------|
| A+ | 95+ | 탁월함 | 배포 가능 |
| A | 90-94 | 매우 좋음 | 경미한 수정 후 배포 |
| B+ | 85-89 | 좋음 | 주석 추가 권장 |
| B | 80-84 | 충분함 | 재검토 권장 |
| C | 70-79 | 미흡 | 수정 필요 |
| D | 60-69 | 부족 | 상당한 수정 필요 |
| F | 0-59 | 불충분 | 다시 작성 권장 |

### 빨간 신호 (위험)
- 허구 감지 (특히 액션에서)
- 주요 결정사항 누락
- 액션 담당자 미정
- 일치도 80점 미만

## ⚠️ 주의사항

1. **컨텍스트 의존성**
   - LLM은 문맥을 이해하려고 노력하지만, 회의의 정치적/업무적 맥락은 100% 정확히 인지 못할 수 있음
   - 최종 판단은 인간 리뷰어가 해야 함

2. **날짜 및 담당자 검증**
   - 마감일이 현실적인지는 검증하지 않음 (비즈니스 로직 필요)
   - 담당자 존재 여부도 검증하지 않음

3. **언어 및 번역**
   - 한글 문서 분석은 잘 되지만, 혼합 언어는 정확도 저하 가능

4. **API 비용**
   - 모든 검증이 Claude API를 사용하므로, 대량 검증 시 비용 고려
   - 배치 처리로 비용 최적화 권장
