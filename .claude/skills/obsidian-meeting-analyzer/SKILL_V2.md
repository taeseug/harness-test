# 🤖 Obsidian 회의 자동 분석 스킬 (v2)

## 📋 개요

**Claude가 직접 분석합니다** (API 키 불필요!)

- ✅ 회의 파일 읽기
- ✅ Claude로 자동 분석
- ✅ 요약 생성 (3-5문장)
- ✅ 액션 아이템 추출
- ✅ 의사결정 사항 기록
- ✅ JSON 저장
- ✅ ACTION_ITEMS.md 자동 갱신

---

## 🎯 사용 방법

### 방법 1: 간단한 지시

```
"obsidian-vault/Meetings/2026-06-11-제품주간회의.enhanced.md 파일을 분석해줄래?"
```

### 방법 2: 배치 분석

```
"obsidian-vault/Meetings 폴더의 모든 회의를 분석해줘"
```

### 방법 3: 특정 작업 요청

```
"이 회의에서 누가 뭘 해야 하는지 정리해줄래?"
```

---

## 📊 분석 프로세스

### Claude가 자동으로 하는 일:

1️⃣ **파일 읽기**
   - `obsidian-vault/Meetings/*.enhanced.md` 읽기
   - 메타데이터 및 내용 파악

2️⃣ **분석**
   ```
   - 요약: 핵심 내용 3-5문장
   - 액션: 누가, 뭘, 언제까지
   - 결정: 뭘 결정했고, 왜
   - SSOT: 영향받는 규칙
   ```

3️⃣ **결과 저장**
   ```json
   {
     "summary": "회의 요약",
     "actions": [
       {
         "item": "작업",
         "owner": "담당자",
         "due_date": "YYYY-MM-DD",
         "priority": "높음/중간/낮음"
       }
     ],
     "decisions": [
       {
         "decision": "결정",
         "reason": "근거",
         "owner": "담당자"
       }
     ],
     "ssot_impact": ["영향도"]
   }
   ```

4️⃣ **자동 갱신**
   - `obsidian-vault/Meetings/analysis_*.json` 생성
   - `obsidian-vault/Meetings/ACTION_ITEMS.md` 추가

## 💡 사용 예시

### 예시 1: 단일 회의 분석

```
사용자: 2026-06-11 회의를 분석해줄래?

Claude:
✅ 파일 읽음: 2026-06-11-제품주간회의.enhanced.md
🤖 분석 중...
✅ 분석 완료

📝 요약:
결제 연동 진행 상황 보고 (A사와의 커뮤니케이션 지연 인식),
정산 주기 재논의 (고객사 요청 vs 개발 리소스 - 보류),
온보딩 이탈률 분석 결과 공유 (3단계에서 42% 이탈 발견)

📌 액션 아이템 (3개):
1. 🔴 [[강태우]] - A사와 상위 에스컬레이션 (마감: 2026-06-15)
2. 🟡 [[이지혜]] - 고객사별 정산 주기 가능성 검토 (마감: 2026-06-18)
3. 🟡 [[최민아]] - 3단계 이탈률 개선 A/B 테스트 설계 (마감: 2026-06-25)

✅ 의사결정 (2개):
1. 결제 연동 일정 재조정 (근거: A사 담당 부서 확인 병목)
2. 정산 주기 보류 결정 (근거: 고객사별 조건 검토 필요)

✅ 결과 저장:
- JSON: obsidian-vault/Meetings/analysis_20260811_143000.json
- ACTION_ITEMS.md 자동 갱신 완료
```

### 예시 2: 모든 회의 분석

- 최신 분석: analysis_20260811_143000.json
