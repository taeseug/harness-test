## 🎯 사용법

### 새로운 결정사항 추가
1. `_decision-template.md` 복사
2. 파일명: `YYYY-MM-DD-결정주제.md`
3. 메타데이터 작성
4. 상세 내용 작성
5. 관련 회의 링크 추가

### 템플릿 섹션

```
---
date: 결정 날짜
type: decision
status: 확정|보류|폐기
owner: 담당자
category: 기술|비즈니스|운영
impact: 높음|중간|낮음
---
```
