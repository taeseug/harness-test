# 회의록 템플릿

**복사 후 사용하기**:
1. 이 파일 복사
2. 파일명: `YYYY-MM-DD_meeting-topic.md` 로 변경
3. 날짜, 참여자, 주제 입력

## 💡 회의록 작성 팁

### Do ✅
- **구체적**: "좋다" X → "지연시간 30% 감소" O
- **결정 명확**: 의견 vs 결정 구분
- **행동항목**: 누가, 무엇을, 언제까지
- **링크**: 관련 SSOT 문서 참조

### Don't ❌
- **추상적**: "나중에 논의" X
- **미결정**: "아직 모름" X
- **담당자 불명**: "누군가 하겠지" X
- **고립**: 링크 없이 standalone 문서 X

## 🔄 후속 처리

### 회의 직후
1. 이 파일을 저장소에 커밋
2. [[SSOT]] 의 "최근 회의록"에 링크 추가
3. 행동항목 담당자에게 공유

### 영향받는 SSOT 문서 수정
- 해당 문서 열기
- 변경사항 적용
- 버전 업데이트
- 이 회의록을 참조로 추가

### 마감일 추적
- 모든 행동항목의 마감일 달력 동기화
- 마감 3일 전 리마인더
