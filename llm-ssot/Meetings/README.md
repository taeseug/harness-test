## 🎯 각 디렉토리/파일 역할

### 📁 RAW/ (원본 보관소)

**목적**: 원본 회의록 보호
**파일**: 6개 원본 회의록
**규칙**: 
- 🔒 읽기 전용
- ❌ 수정 금지
- ✅ 복사 및 분석은 자유

**자세히**: [[RAW/README.md]]

---

### 📝 Enhanced.md 파일들

**목적**: 원본을 설계한 템플릿으로 구조화

**특징**:
```
✅ 배경/의견/결정 분리
✅ 담당자/마감일 명시
✅ 액션 아이템 추출 용이
✅ SSOT 영향도 분석
✅ 자동화 가능한 형식
```

**예시**: `2026-04-16-제품주간회의.enhanced.md`
```
회의 정보
├─ 날짜, 장소, 참석자
│
논의 내용
├─ 안건별
│  ├─ 배경
│  ├─ 의견 (각자 입장 + 근거)
│  ├─ 토론 요점
│  └─ 결정 상태
│
결정사항
├─ Decision-001
├─ Decision-002
├─ ...
│
액션 아이템
├─ 긴급 (3일)
├─ 일반 (1-2주)
├─ 장기 (2주+)
│
SSOT 영향도
└─ 어떤 LLM 규칙이 영향받는가?
```

### 📌 ACTION_ITEMS.md

**목적**: 모든 액션 아이템의 중앙 추적

**포함 내용**:
- 담당자별 현황
- 마감일 기준 우선순위
- 완료 여부 추적
- 지연 패턴 분석

**사용법**:
```
매일 확인: 마감 임박 항목 체크
매주 갱신: 완료 상태 업데이트
월말 정리: 완료/보류/연기 분류
```

**통계** (현재):
```
총 14개
✅ 완료: 11개 (79%)
⏳ 진행: 2개 (14%)
⏸️ 보류: 1개 (7%)
```

---

### 📊 MEETINGS_ANALYSIS.md

**목적**: 모든 회의를 종합 분석

**포함 내용**:
- Executive Summary
- 주요 결정사항 (Tier 1-3)
- 반복되는 이슈 분석
- 의사결정 패턴
- 담당자별 성과
- 향후 계획

**예시**:
```
온보딩 문제:
- 5월 발견 (CS 피드백)
- 6월 정량화 (42% 이탈)
- 6월 개선안 검토
- 7월 배포 & 검증
- 결과: 27% (35% 개선)

결제 연동:
- 4월 목표: 5월말
- 5월-7월: 3회 지연 (외부 의존)
- 7월: 에스컬레이션 성공
- 현재: 8월 13일 목표
```

### 🔧 HARNESS.md & HARNESS_CONFIG.yaml

**목적**: 회의 자동화 시스템

**HARNESS.md**: 회의 생명주기 (전→중→후)
**HARNESS_CONFIG.yaml**: 자동화 설정

**사용**:
```bash
# Pre-meeting
/claude meeting:new 2026-08-24-주간회의

# Post-meeting
/claude meeting:process ./2026-08-24-주간회의.enhanced.md
```
