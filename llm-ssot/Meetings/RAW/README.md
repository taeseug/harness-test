## 🔄 RAW → Enhanced 변환 프로세스

```
Step 1: RAW 파일 읽기
   └─ 이 디렉토리에서 원본 읽음

Step 2: Enhanced 형식으로 구조화
   └─ ../2026-XX-XX.enhanced.md로 저장
      (같은 레벨, 다른 파일명)

Step 3: 액션 아이템 추출
   └─ ../ACTION_ITEMS.md에 추가

Step 4: 분석 업데이트
   └─ ../MEETINGS_ANALYSIS.md에 반영
```

### 만약 RAW가 손상되면?

```
1️⃣ Enhanced 파일 확인
   └─ 대부분의 정보는 Enhanced에 있음

2️⃣ MEETINGS_ANALYSIS.md 확인
   └─ 분석은 별도 백업

3️⃣ ACTION_ITEMS.md 확인
   └─ 액션 아이템은 완전히 추출됨

⚠️ RAW가 손상되어도 Enhanced + 분석으로 충분히 복구 가능!
```

## 🛡️ 파일 권한 관리

### 권장 설정

```bash
# RAW 파일을 읽기 전용으로 설정 (선택사항)
chmod 444 *.md

# 또는 디렉토리 전체를 읽기 전용으로
chmod 555 ./

# 복구 필요시:
chmod 644 *.md
chmod 755 ./
```

### Git 설정

```gitignore
# 실수로 RAW 수정 방지
*.md.backup

# 버전 관리는 계속
RAW/*.md  # 버전 관리 O
```

## 📝 RAW 파일 포맷

### 표준 형식

```yaml
---
출처: Notion (또는 다른 소스)
notion_url: https://www.notion.so/...
회의일: YYYY-MM-DD
가져온시점: YYYY-MM-DD
참석: 이름1(역할), 이름2(역할)
---

# YYYY-MM-DD 회의명

## 안건
1. 주제1
2. 주제2

## 주제1
- 발언자: 내용
- 발언자: 내용

## 결정사항
- 결정: 내용
- 담당: 이름
- 마감: YYYY-MM-DD
```

### 필수 정보

- ✅ 날짜 (YYYY-MM-DD)
- ✅ 참석자 (이름 + 역할)
- ✅ 주요 논의 내용
- ✅ 결정사항
- ✅ 액션 아이템

## 🔍 RAW 파일 검증 체크리스트

새 RAW 파일 추가 시:

- [ ] 파일명: `YYYY-MM-DD-주제.md` 형식
- [ ] 헤더: `---` 메타데이터 포함
- [ ] 날짜: YYYY-MM-DD 형식 일관성
- [ ] 참석자: 이름 + 역할 표기
- [ ] 결정: 명확한 결정사항 기록
- [ ] 액션: 담당자 + 마감일 명시
- [ ] 인코딩: UTF-8 (한글 지원)
- [ ] 줄바꿈: Unix 스타일 (LF)

## 📞 문제 상황 대응

### 만약 RAW 파일이 실수로 수정됐다면?

```
1️⃣ 즉시 커밋하지 말 것
2️⃣ Git 히스토리에서 원본 복구
   git checkout HEAD~1 -- Meetings/RAW/

3️⃣ Enhanced에서 수정사항 정리
4️⃣ METADATA.md에 사건 기록
```

### 만약 RAW 파일이 삭제됐다면?

```
1️⃣ Git 히스토리에서 복구
   git restore Meetings/RAW/파일명.md

2️⃣ 최악의 경우, Enhanced에서 재구성
   (85% 정도 복구 가능)

3️⃣ 백업 파일 확인
```
