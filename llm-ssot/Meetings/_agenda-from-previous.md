# 이전 회의록 기반 아젠다 생성 가이드

**목적**: 팀이 이전 회의록을 참고하여 다음 회의 아젠다를 구성할 때 사용

---

## 📋 아젠다 수집 프로세스

### 1단계: 이전 회의록 검토 (담당자: 의장)

```
이전 회의록 확인:
├─ 미결정 사항 (Pending Decisions)
├─ 진행 중 행동항목 (In Progress Action Items)
├─ 완료되지 않은 항목 (Overdue Items)
└─ 새로운 이슈 (New Issues Raised)
```

### 2단계: 아젠다 항목 분류

#### Type A: 의존도 높음 (높은 우선순위)
```
- 다른 항목의 선행조건인 항목
- 마감일이 임박한 항목
- 팀 차단(blocking) 항목

예:
- [ ] 이전 회의에서 미결정된 모델 선택 결정
- [ ] 마감일: 2026-08-15 (3일 남음)
```

#### Type B: 일반 진행사항 (중간 우선순위)
```
- 정상 진행 중인 항목
- 예상대로 진행되는 항목
- 상태 업데이트 필요

예:
- [ ] 프롬프트 엔지니어링 가이드 작성 진행율 80%
```

#### Type C: 정보 공유 (낮은 우선순위)
```
- 완료된 항목 보고
- FYI성 항목
- 회의 말미에 다룰 수 있는 항목

예:
- [ ] 평가 방법론 문서 완성
```

## 🔍 체크리스트: 이전 회의록 검토

이전 회의의 `_meeting-template.md` 를 열어서 확인:

```
[ ] 행동항목 (Action Items) 섹션 확인
    - [ ] 마감일 지난 항목이 있는가?
    - [ ] 진행 상황이 어디까지인가?
    - [ ] 추가 지원이 필요한가?

[ ] 결정사항 (Decisions) 섹션 확인
    - [ ] 확정되지 않은 결정이 있는가?
    - [ ] 추가 정보가 필요한가?
    - [ ] 구현이 시작되었는가?

[ ] SSOT 영향 섹션 확인
    - [ ] 변경된 SSOT 항목들이 있는가?
    - [ ] 다른 팀에 영향을 미쳤는가?

[ ] 참고자료 (References) 섹션 확인
    - [ ] 언급된 문서들이 최신인가?
    - [ ] 새로운 리소스가 추가되었는가?
```

## 📊 아젠다 템플릿 (이전 회의록 기반)

```markdown
# 회의 아젠다 - [날짜]

## 이전 회의 Follow-up

### Type A: 의존도 높음 (우선순위 1)
- [ ] **[담당자명]** - [항목명]
  - 진행율: X%
  - 상태: 🟢 진행중 / 🟡 지연 / 🔴 미작업
  - 이전 회의: [[Meetings/YYYY-MM-DD_meeting-notes]]

- [ ] **[담당자명]** - [항목명]
  - 진행율: Y%
  - 상태: 🟡 지연 (원인: ...)
  - 필요 지원: [지원사항]

### Type B: 일반 진행사항 (우선순위 2)
- [ ] 상태 업데이트: [항목]
  - 이전 회의: [[Meetings/YYYY-MM-DD_meeting-notes]]

### Type C: 정보 공유 (우선순위 3)
- [ ] 보고: [완료 항목]
```

## 🛠️ 실행 방법

### 방법 1: 수동으로 아젠다 작성

1. **`Meetings/` 폴더 열기**
   ```
   가장 최근 회의록 찾기: 
   ls -lt Meetings/*.md | head -5
   ```

2. **이전 회의록 열기**
   ```
   [[Meetings/2026-08-10_meeting-notes]]
   ```

3. **각 섹션 검토**
   - 행동항목: 진행율 확인
   - 결정사항: 미결정 항목 확인
   - SSOT 영향: 변경사항 확인

4. **아젠다 작성**
   - Type A 항목부터 우선 입력
   - 담당자, 진행율, 상태 명시
   - 이전 회의 링크 추가

### 방법 2: 마크다운 쿼리 사용 (Obsidian)

Obsidian의 DataviewJS를 사용하여 자동 생성:

```dataview
LIST
FROM "Meetings"
WHERE status = "in_progress" OR status = "overdue"
GROUP BY type
SORT priority DESC
```

## 💡 팁

### ✅ Do
- **정기적**: 매 회의마다 이전 회의록 검토
- **변화 추적**: 진행율을 구체적 숫자로 기록
- **링크**: 이전 회의록과 SSOT를 항상 참조
- **일관성**: 담당자, 마감일, 상태를 명확히

### ❌ Don't
- **지연 항목 무시**: 지연이 보이면 아젠다 최상단으로
- **마감 무시**: "언젠가" X → 구체적 날짜 명시
- **담당자 불명**: "팀에서" X → 이름 명시
- **고립**: 이전 회의와의 연결고리 끊기
