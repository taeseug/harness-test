### ⚠️ Warning Case (경고)
```
일부 기능이 예상과 다르게 작동
├─ 예: Dataview 쿼리가 렌더링 안 됨
├─ 예: 링크 일부가 작동 안 함
└─ 예: 사용자 인터페이스 혼란

대응:
1. 문제 문서화
2. 원인 분석
3. 즉시 수정 가능하면 수정
4. 불가능하면 개선 사항 기록

최종: 🟡 경고 → 재검토 필요
```

### ❌ Failure Case (실패)
```
주요 기능이 작동하지 않음
├─ 예: 회의 파일 생성 실패
├─ 예: 액션이 대시보드에 반영 안 됨
└─ 예: Obsidian 앱 자체 문제

대응:
1. 즉시 세션 중지
2. 근본 원인 파악
3. 긴급 수정
4. 재테스트 후 재진행

최종: 🔴 실패 → 재설계 필요
```
