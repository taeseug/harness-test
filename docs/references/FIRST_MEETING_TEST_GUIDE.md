## ⚠️ 문제 해결 (Troubleshooting)

### 문제 1: 템플릿이 안 나타남
```
증상: 새 파일 생성 시 템플릿 선택 옵션 없음

해결:
1. Templater 플러그인 확인
   Obsidian → Settings → Community Plugins → Templater
   
2. 템플릿 폴더 지정
   Templater Settings → Template folder location: Templates/
   
3. Obsidian 재시작
```

### 문제 2: Dataview 쿼리가 렌더링 안 됨
```
증상: DASHBOARD.md에서 "Dataview Render" 메시지만 표시

해결:
1. Dataview 플러그인 활성화 확인
2. 쿼리 문법 확인 (backticks 3개로 감싸기)
3. 파일 저장 후 새로고침
   Cmd+S → Cmd+Shift+R
```

### 문제 3: 링크가 작동 안 함
```
증상: [[파일명]] 링크 클릭해도 열리지 않음

해결:
1. 파일명 정확성 확인
2. 확장자 확인 (.md는 생략)
3. 폴더 경로 확인
```

### 문제 4: 액션이 대시보드에 안 보임
```
증상: ACTION_ITEMS.md를 수정했지만 DASHBOARD.md에 반영 안 됨

해결:
1. ACTION_ITEMS.md 저장 확인 (Cmd+S)
2. DASHBOARD.md 새로고침 (Cmd+Shift+R)
3. Obsidian 재시작 (최후 수단)
```
