## 개요

### 🎯 이 스킬이 하는 일

```
Claude Code에서 지시
    ↓
Claude가 회의 파일 읽기
    ↓
자동 분석 (요약, 액션, 결정)
    ↓
JSON 저장 + ACTION_ITEMS.md 갱신
    ↓
완료!
```

### ✨ 핵심 특징

- ✅ **API 키 불필요** - Claude가 자동으로 처리
- ✅ **한글 완벽 지원** - 한글 파일명도 OK
- ✅ **자동 저장** - JSON + ACTION_ITEMS.md 자동 갱신
- ✅ **링크 지원** - `[[담당자]]` Obsidian 링크 포함
- ✅ **구조화된 결과** - JSON으로 저장되어 파싱 가능

### 🎁 생성되는 것

```
1. analysis_YYYYMMDD_HHMMSS.json
   └─ 위치: obsidian-vault/Meetings/
   └─ 내용: 요약, 액션, 결정, SSOT 영향

2. ACTION_ITEMS.md 갱신
   └─ 위치: obsidian-vault/Actions/
   └─ 내용: 새로운 액션 아이템 자동 추가
```

```

"obsidian-vault/Meetings 폴더의 2026-06-11 회의 분석해줘"
```

**Claude가 자동으로:**
- ✅ 파일 찾음
- ✅ 내용 읽음
- ✅ 분석 완료

---

### 방법 2️⃣: 모든 회의 분석

```
"지난 회의들을 모두 분석해줄래?"

또는

"obsidian-vault/Meetings의 모든 회의 분석해줘"
```

**Claude가:**
- ✅ 모든 `.enhanced.md` 파일 감지
- ✅ 순차적으로 분석
- ✅ 각각 JSON 저장 + ACTION_ITEMS.md 추가

```
"이 회의에서:
```

**Claude가 맞춤형 분석 제공**

## 자주 묻는 질문

### Q1: API 키가 필요한가요?
**A:** 아니요! Claude가 자동으로 처리합니다. V2 스킬의 장점입니다.

### Q2: 회의 파일 형식이 정해져 있나요?
**A:** 마크다운(`.md`) 파일이면 되지만, 다음 형식을 권장합니다:
```markdown
---
date: 2026-06-11
type: meeting
participants: [이지혜, 박준서]
---

# 회의록 제목

## 논의 내용
...

## 결정사항
...

## 액션 아이템
...
```

### Q3: 한글 파일명도 지원하나요?
**A:** 네! 완벽하게 지원합니다. `2026-06-11-제품주간회의.enhanced.md`도 OK.

### Q4: 분석 결과를 다시 수정할 수 있나요?
**A:** 네! `analysis_*.json`을 직접 수정하거나, Claude에게 다시 분석 요청할 수 있습니다.

### Q5: ACTION_ITEMS.md가 자동으로 지워지지는 않나요?
**A:** 아니요! 새로운 액션을 **추가만** 합니다 (누적). 기존 내용은 보존됩니다.

### Q6: 같은 회의를 여러 번 분석하면?
**A:** 각 분석마다 새로운 JSON 파일이 생성됩니다:
- `analysis_20260811_143000.json`
- `analysis_20260811_150000.json`
- `analysis_20260811_160000.json`

### Q7: 여러 회의를 한 번에 분석하면 느리지 않나요?
**A:** Claude가 순차적으로 처리하므로 시간이 좀 걸릴 수 있습니다.  
대량 분석이 필요하면 한 번에 3-4개씩 나누어 요청하세요.

### Q8: 분석 결과를 Slack에 보낼 수 있나요?
**A:** 지금은 직접 보내기는 안 되지만, JSON 결과를 복사해서 보낼 수 있습니다.

### Q9: 특정 용어로 액션을 분류할 수 있나요?
**A:** 네! 분석 요청 시 지정하면 됩니다:
```
"액션들을 다음 카테고리로 분류해줄래:
- Development
- Design
- Product
- Business"
```

### Q10: 완료된 액션을 체크하는 방법은?
**A:** ACTION_ITEMS.md에서 수동으로 체크 표시하거나, JSON의 `status`를 `✅`로 변경하세요.
