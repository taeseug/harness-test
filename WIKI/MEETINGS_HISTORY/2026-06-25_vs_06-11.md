```

```

**평가**:
```

→ A안은 문제를 뒤로 미루는 것뿐
```

### B안: 입력 단계 단순화

**방식**:
```
기존: 필수 항목 7개
B안: 필수 항목 3개로 축소
추가: 카드 정보 스캔 기능

시간:
- 스캔 기능: 2주 (외부 SDK)
- 항목 축소만: 3일

제안: 1차(항목 축소) + 2차(스캔)로 나누기
```

**장점**:
```
✅ 근본적인 개선 (이탈 원인 제거)
✅ 입력 프로세스 단순화
✅ 실제 매출 확보 가능
```

**단점**:
```
❌ 개발 시간 필요 (스캔 2주)
❌ 복잡도 증가
```
