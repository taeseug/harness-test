⚙️ Step 1: Templater 플러그인 설정

접근 경로

Settings (⚙️) → Community Plugins → Templater

🔧 확인해야 할 설정

  • Template folder location: Templates
  • Trigger Templater on new file creation: ✅ ON
  • Automatic jump to cursor: ✅ ON

⚠️ 주의: "Templates" 폴더명이 정확해야 합니다 (대소문자 구분)

💡 설정 후 저장을 꼭 눌러주세요

📅 Step 2: Periodic Notes 설정

접근 경로

Settings (⚙️) → Periodic Notes

🔧 Daily Notes 섹션 설정

  • Enable Daily notes: ✅ ON
  • Daily folder: Daily
  • Daily format: YYYY-MM-DD
  • Template file: Templates/daily

✅ 결과: 매일 자동으로 일일노트 생성!

🧪 Step 3: 템플릿 테스트

3-1. Daily Note 자동 생성 테스트

Cmd + P (명령팔레트)

↓

Periodic Notes: Open today note 검색 후 실행

↓

✅ Daily 폴더에 오늘 날짜 파일이 생성됨

3-2. 회의 템플릿 생성 테스트

Cmd + P

↓

Templater: Create new note from template 검색

↓

📄 meeting-new 선택

↓

✅ Meetings 폴더에 파일 생성 & 템플릿 적용

🔗 Step 4: 링크 자동완성 확인

테스트 방법

1. 아무 파일이나 열기

2. [[ 입력하기

3. 자동완성 목록이 나타나는지 확인

✅ 예상 결과:

  • [[ACTION_ITEMS]] 자동 완성
  • [[담당자]] 자동 완성
  • [[회의]] 자동 완성
💡 Escape를 눌러서 자동완성 목록을 닫을 수 있습니다

쿼리 테스트 파일 생성

✅ 테이블로 렌더링되어야 성공!

⚠️ 렌더링 안 되면: Cmd + Shift + R (새로고침) 시도

✅ 최종 체크리스트

Templater 설정 - Templates 폴더 경로 확인
Periodic Notes 설정 - Daily 자동 생성 설정
Daily Note 테스트 - 오늘 날짜 파일 생성됨
회의 템플릿 테스트 - meeting-new 적용 확인
링크 자동완성 - [[ 입력 시 목록 표시
Dataview 쿼리 - 테이블로 렌더링됨

🎉 모든 체크가 완료되면 성공입니다!

🔧 문제 해결

Daily Note가 생성 안 되면

  1. Periodic Notes 플러그인이 활성화되어 있나?
  2. Daily 폴더가 존재하나? (Obsidian-vault/Daily/)
  3. 날짜 형식이 YYYY-MM-DD인가?
  4. Obsidian 재시작 시도

템플릿이 자동 생성 안 되면

  1. Templater 활성화 확인
  2. Templates 폴더에 파일이 있나?
  3. meeting-new.md 정확한 이름 확인
  4. Obsidian 재시작 후 재시도

Dataview 쿼리가 렌더링 안 되면

  1. Dataview 플러그인 활성화 확인
  2. Cmd + S 저장
  3. Cmd + Shift + R 새로고침
  4. Obsidian 재시작
