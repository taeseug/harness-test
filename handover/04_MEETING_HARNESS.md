# 04_MEETING_HARNESS.md - 회의 자동화 가이드

**소요시간**: 30분

---

## 🔄 회의 생명주기 (3단계)

### 1️⃣ 사전 준비 (회의 24시간 전, 5분)

**의장이 하는 일**:
```
Obsidian 명령어 팔레트 (Cmd+P)
  → "Templater: Insert Template"
  → "meeting-new" 선택
  → 완료!

자동 생성됨:
  ✅ 아젠다 초안
  ✅ 배경 자료 (SSOT 문서, 이전 회의)
  ✅ 팀 Slack 알림
```

### 2️⃣ 회의 진행 (회의 중, 실시간)

**기록자가 기록할 것**:

```
📋 회의 정보
  - 날짜, 시간, 참석자
  - 의장, 기록자
  
📝 안건별 논의
  배경: [문제 설명]
  의견: **[이름1]**: [의견]
       **[이름2]**: [의견]
  포인트: [핵심 쟁점]
  
✅ 결정사항
  ✅ 결정: [정확한 내용]
  근거: [왜?]
  담당: [누가]
  마감: YYYY-MM-DD
  
📌 행동항목
  [ ] **[담당자]** - [작업] - 마감: YYYY-MM-DD
```

**필수 형식**:
- 이름: `[이름]` (괄호 필수)
- 날짜: `YYYY-MM-DD` (형식 정확하게)
- 담당자: 반드시 명시 (없으면 자동 처리 불가)

### 3️⃣ 사후 처리 (회의 후 24시간 이내, 1분)

**의장이 하는 일**:
```
Obsidian 명령어 팔레트
  → "meeting:process" 검색
  → 파일 선택
  → 완료!

Claude가 자동 처리:
  ✅ 요약 생성
  ✅ 액션 아이템 추출
  ✅ SSOT 영향 분석
  ✅ ADR 초안 생성
  ✅ SSOT 자동 업데이트
  ✅ Slack 알림
```

**결과**:
- `Meetings/ACTION_ITEMS.md` 업데이트
- `Decisions/ADR-NNN.md` 생성 (Type B 이상)
- `SSOT.md` 자동 링크 추가

## 🎯 액션 아이템 추적

### 추출 규칙

```
찾는 패턴:
  [ ] **[담당자]** - [작업] - 마감: YYYY-MM-DD

변환됨:
  Owner: [담당자]
  Task: [작업]
  Deadline: YYYY-MM-DD
  Priority: 자동 계산 (마감까지 남은 일수)
  Status: ⏳ 진행 대기
```

## 📌 ADR (의사결정 기록)

### 자동 생성 조건

```
Type A (긴급): 즉시 ADR 생성
Type B (일반): 회의 후 ADR 생성
Type C (경미): ADR 불필요
```

### ADR 포맷

```
파일명: Decisions/ADR-NNN-[kebab-case].md

내용:
  Title: 의사결정 제목
  Status: Draft / Review / Approved
  Context: 왜 필요했나?
  Decision: 뭘 결정했나?
  Rationale: 왜 이렇게?
  Consequences: 어떤 영향?
  Alternatives: 다른 방법?
  Meeting Reference: [[Meetings/...]]
```

## 📊 실제 예시 (간단한 버전)

**회의**: 2026-08-17 모델 선택 논의 (60분)

```
## 📝 논의

### 안건 1: 현황 점검
배경: Sonnet을 모든 작업에 사용 중. 비용 3배 증가 우려.

의견:
- **이름1**: "빠른 응답 필요 → Haiku 검토"
- **이름2**: "비용 절감 중요 → Haiku 가능"
- **이름3**: "정확도 우려 → Opus 혼용?"

포인트: Haiku는 경량 작업 적합. 명확한 기준 필요.

## ✅ 결정
✅ 3가지 모델 기준으로 통일
근거: 비용 절감 + 속도 개선

## 📌 액션
[ ] **이름1** - Haiku vs Sonnet 벤치마크 - 마감: 2026-08-24
[ ] **이름2** - 비용 분석 - 마감: 2026-08-24
[ ] **이름3** - 팀 가이드 작성 - 마감: 2026-08-31

## 🔗 SSOT 영향
- [[model-selection]] - 3가지 기준 추가
- [[prompt-engineering]] - 모델별 최적화 추가
```

## 🎯 자주 하는 질문

**Q: 회의 중 기록이 늦어도 되나요?**
A: 아니요. 결정사항만이라도 실시간으로 기록해야 자동화 가능.

**Q: 담당자를 누가 정하나요?**
A: 회의 중 의장 또는 Owner가 명시. 없으면 Owner 기본값.

**Q: 마감일을 꼭 정해야 하나요?**
A: 네. 자동 추적이 안 되기 때문에 필수.

**Q: 액션 아이템이 누락되었어요**
A: [[담당자]]와 마감일 형식 확인. 패턴: `[ ] **[이름]** - [작업] - 마감: YYYY-MM-DD`

**Q: 회의록을 언제까지 저장하나요?**
A: 계속. 과거 결정 참고용. 아카이브 안 함.
